# بازی پهباد شاهد — سورس کامل اندروید

بازی اکشن/استراتژی «پهباد شاهد» بر اساس سند طراحی بازی (GDD) شما، به صورت **پروژه‌ی کامل و بومی اندروید (Kotlin)** نوشته شده است.
تمام متن‌ها، منوها، اعداد و رابط کاربری **کاملاً فارسی** هستند (اعداد هم با ارقام فارسی نمایش داده می‌شوند).

> بدون هیچ کتابخانه‌ی بیرونی، بدون Unity و بدون Godot. رندر سه‌بعدی، فیزیک پرواز، افکت‌ها و صداها همه داخل خود پروژه پیاده‌سازی شده‌اند.

---

## ۱. ساخت پروژه (Build)

### روش پیشنهادی: Android Studio
1. پوشه‌ی `shahed-drone` را از حالت فشرده خارج کنید.
2. در Android Studio: `File → Open` و انتخاب پوشه‌ی `shahed-drone`.
3. اگر پیام Gradle Wrapper دیدید، گزینه‌ی `Use Gradle wrapper` یا `Sync` را بزنید (اندروید استودیو خودش فایل‌های wrapper را می‌سازد).
4. `Build → Build Bundle(s) / APK(s) → Build APK(s)`.

### روش خط فرمان
```bash
cd shahed-drone
# فقط یک بار: ساخت فایل‌های wrapper (نیازمند نصب Gradle 8.x)
gradle wrapper
./gradlew assembleDebug        # خروجی: app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease      # نسخه انتشار (نیازمند امضا)
```

پیش‌نیازها: JDK 17، Android SDK 34، Gradle 8.2 (یا wrapper)، AGP 8.2.2، Kotlin 1.9.22.
اگر فایل `local.properties` ندارید، Android Studio خودش آن را با `sdk.dir` می‌سازد.

- حداقل اندروید: **API 24 (اندروید ۷)**
- جهت صفحه: افقی (Landscape)
- حجم APK: حدود ۲ مگابایت (بدون فایل‌های صوتی/تصویری بیرونی)

## ۴. سفارشی‌سازی سریع

**فونت فارسی اختصاصی:** فایل `vazirmatn.ttf` (و اختیاری `vazirmatn-bold.ttf`) را در
`app/src/main/assets/fonts/` بگذارید؛ بازی خودش آن را برمی‌دارد، وگرنه فونت سیستم استفاده می‌شود.

**افزودن مرحله جدید:** در `data/Levels.kt` یک `LevelDef` به لیست `all` اضافه کنید
(فاصله، تعداد پدافند، رادار، اخلال، باد، محدودیت زمان، بونوس و متن بریفینگ).

**تنظیم سختی:** مقادیر `reload` پدافند در `World.buildDefenses` و ضریب دقت در
`Mission.fireMissile` را تغییر دهید.

**تنظیم حس پرواز:** `turnRate` و `pitchRate` در `Mission.update` و حساسیت تیلت
(`sens = 4.2f`) در `GameScreen.onSensorChanged`.

**صداهای واقعی:** فایل‌های صوتی را در `res/raw` بگذارید و بدنه‌ی متدهای `GameAudio`
را با `SoundPool` جایگزین کنید؛ امضای متدها تغییری لازم ندارد.

**تبلیغات / پرداخت:** نقاط اتصال طبیعی: `ResultScreen` (تبلیغ پاداشی برای سکه دوبرابر)
و `ShopScreen` (خرید سکه).

## ۵. راهنمای بازی

- **پرتاب:** در صفحه‌ی آماده‌ی پرتاب، یک ضربه روی صفحه.
- **هدایت:** تیلت گوشی (پیش‌فرض) یا جوی‌استیک مجازی سمت چپ (از تنظیمات).
- **سرعت:** کشیدن انگشت در نیمه‌ی راست صفحه به بالا/پایین.
- **بوست:** دکمه‌ی پایین راست را نگه دارید (سوخت بیشتری می‌سوزاند).
- **دوربین:** دکمه‌ی بالای بوست، بین نمای سوم شخص و دوربین نوک پهباد.
- **نکته تاکتیکی:** در محدوده‌ی رادار (دایره آبی) زیر سقف ارتفاع پرواز کنید؛ ارتفاع کم
  دقت پدافند را به شدت پایین می‌آورد. بونوس‌های زرد تا ۵۰۰ امتیاز اضافه می‌دهند.
