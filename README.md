# پهپاد شاهد: سورس نسخهٔ گرافیکی ۰.۰.۳

بر پایهٔ سورس اندروید ۰.۰.۲ ارسالی. گرافیک جدید در کد اصلی Kotlin + Canvas و داخل assets بازی تعبیه شده است؛ این بسته یک نمونهٔ وب یا صرفاً چند تصویر جداگانه نیست.

**راهنمای کامل تغییرات، ساخت، محدودیت‌ها و تست: [GRAPHICS-UPDATE-FA.md](GRAPHICS-UPDATE-FA.md)**

APK در محیط تولید بسته کامپایل نشده است. GitHub Actions همراه پروژه debug APK می‌سازد و lint را اجرا می‌کند، بدون نیاز به کلید امضا و بدون انتشار خودکار release.

## فایل‌های کلیدی

- `game/Scene3D.kt`: پرسپکتیو، برش سطوح جامد و صف عمق مشترک تصاویر و هندسه.
- `game/SceneryArt.kt`: بافت زمین در مختصات جهان، آسمان و مه، جاده و سایهٔ تقریبی.
- `game/DroneArt.kt`: بال تصویردار، بدنهٔ حجم‌دار و چرخش سه‌محوره.
- `game/WorldRenderer.kt`: اتصال گرافیک جدید به گیم‌پلی اصلی.
- `core/Gfx.kt`: بارگذاری و حافظهٔ نهان تصاویر.
- `app/src/main/assets/gfx/`: تصاویر و بافت‌های بسته‌بندی‌شده.
- `tools/`: بازتولید تصاویر و بررسی‌های مستقل.

مسیر پایهٔ کدهای Kotlin: `app/src/main/java/ir/shahed/pahpad/`.

مستندات اصلی، بدون تغییر و صرفاً برای سابقه: [README-ORIGINAL-0.0.2.md](README-ORIGINAL-0.0.2.md). ادعاهای حجم APK و راهنمای CI آن سند مربوط به نسخهٔ قبلی هستند.
